DeepFilterNet3 - vendored browser engine for noise suppression
==============================================================

Everything here is served from this origin at /js/lib/dfn3/. No third-party
CDN is contacted at runtime.

What the files are
------------------
df_bg.wasm                     Rust engine (DeepFilterNet3 inference + STFT/
                               feature extraction, wasm-bindgen target web).
                               16,418,651 bytes. Obtained from the Mezon build
                               below; this is the only artifact with no
                               independent second source, so it is pinned by
                               hash and is not rebuilt here.
DeepFilterNet3_onnx.tar.gz     Official model weights. Verified byte-identical
                               to upstream Rikorose/DeepFilterNet (see hash).
df.js                          wasm-bindgen glue (initSync, df_create,
                               df_process_frame, df_set_atten_lim,
                               df_set_post_filter_beta). Unmodified. Includes
                               an AudioWorklet TextDecoder/TextEncoder
                               polyfill authored upstream.
package.json                   {"type":"module"} marker so Node tooling can
                               import df.js as ESM. Browsers ignore it.

Measured on this project (scripts/dfn3-bench.mjs, i5-12400, Node/V8 wasm):
  frame 480 samples @ 48 kHz, median 0.32-0.56 ms per 10 ms frame
  (RTF 0.03-0.06, ~4.5% of one core), 28.8 MB linear memory, no growth over
  ~5,000 frames, model load ~0.46 s, wasm compile ~20 ms, algorithmic delay
  30 ms, noise floor attenuation 19.7 dB (atten_lim 20) to 67.7 dB (100).
